# Referencias de apoyo para la estructura del repositorio

Estas son las fuentes externas consultadas para preparar la propuesta de estructura de carpetas, el fichero .gitignore y las normas de versionado del repositorio del TFM. Se incluyen en formato APA séptima edición para que puedan incorporarse a la memoria si se considera oportuno, por ejemplo en el apartado 3.2 o 3.3 del índice.

DrivenData. (s. f.). *Cookiecutter Data Science*. GitHub. Recuperado el 16 de septiembre de 2026, de https://github.com/drivendataorg/cookiecutter-data-science

Conventional Commits. (s. f.). *Conventional Commits 1.0.0*. Recuperado el 16 de septiembre de 2026, de https://www.conventionalcommits.org/en/v1.0.0/

GitHub. (s. f.). *gitignore: A collection of useful .gitignore templates*. GitHub. Recuperado el 16 de septiembre de 2026, de https://github.com/github/gitignore

## Nota

La plantilla Cookiecutter Data Science, desarrollada por DrivenData, es una de las convenciones más extendidas para organizar proyectos de ciencia de datos y ha servido de referencia para separar los datos en raw, interim, processed y external, así como para las carpetas de notebooks, models y src. La estructura final se ha adaptado a las necesidades propias del proyecto, incorporando carpetas específicas para la base de datos, el ETL con Apache Hop y los cuadros de mando, que no forman parte de la plantilla original.
